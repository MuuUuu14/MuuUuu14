# 电影评论情感标注规范

## 标注规则
- **好评（标签=1）**：评论明确表达对电影的喜欢、推荐、肯定或感动
- **差评（标签=0）**：评论明确表达对电影的讨厌、不推荐、否定或失望
- **无效（舍弃）**：纯符号、非中文、内容为空、无法判断情感

## 标注原则
1. 以评论者表达的最终情感为准，不加入个人对电影的主观判断
2. 存在转折但整体情感明确的，以整体为准。如"演员很好但剧情太烂"整体为差评
3. 讽刺反语按字面反方向标注。如"这电影真是太'好看'了（带引号讽刺意味）"标为差评
4. 间接表达也需判断情感。如"中途离场了"、"睡着了三次"标为差评

## 边界案例处理
| 评论 | 标签 | 判断依据 |
|:---|:---|:---|
| 睡着了三次 | 0 | 间接表达无聊，属于差评 |
| 千万别看 | 0 | 明确劝退，差评 |
| 千万别错过 | 1 | 强烈推荐，好评 |
| 笑着笑着就哭了 | 1 | 整体正面，好评 |
| 笑中带泪，难得的好片 | 1 | 整体正面，好评 |
| 被片名耽误的好片 | 1 | 整体正面，好评 |
| 特效还不如十年前 | 0 | 否定比较，差评 |
| 除了海报一无是处 | 0 | 整体否定，差评 |
| 导演你睡得着吗 | 0 | 讽刺质问，差评 |
| 一分给配乐，其他零分 | 0 | 整体否定，差评 |

## 标注质量标准
- 准确率 > 95%（定期抽检）
- 标注员间一致率 > 90%
- 模糊案例必须与审核员讨论决定，不可主观判断
