## 项目一：电影评论情感分析（二分类）
- **技术栈**：Python、Scikit-learn、TF-IDF、逻辑回归
- **数据集**：IMDB 5000条电影评论
- **模型表现**：准确率86.2%，精确率83.6%，召回率88.5%
- **踩坑记录**：
  - 手写数据时好评太弱，模型全猜差评，准确率43%
  - 加了强力好评，准确率涨到61%
  - 加了强力差评反而暴跌到38%，原因是训练和测试数据分布不一致
  - 换成IMDB公开数据集后，准确率涨到86%
- **核心收获**：数据质量决定模型上限，干净统一的数据比换模型管用得多

## 项目二：新闻文本四分类
- **技术栈**：Python、Scikit-learn、TF-IDF、逻辑回归
- **数据集**：20 Newsgroups，3887条新闻，4个类别
- **模型表现**：准确率87.4%
- **各类别表现**：
  - 棒球：精确率92%，召回率90%（最好）
  - 摩托车：精确率80%，召回率91%（精确率偏低，容易误判）
  - 太空科技：精确率90%，召回率85%
  - 政治枪支：精确率91%，召回率83%
- **核心收获**：多分类场景下需要逐类别分析精确率和召回率，而不是只看总准确率
