# Prompt 优化案例合集

## 案例：电影评论情感分析脚本生成

### V1 初始版
**Prompt**：
写一个情感分析代码

**输出**：
代码太简略，没有注释，没有评估指标，无法判断模型好坏。

**问题**：需求不明确，AI自由发挥，产出不可用。

### V2 改进版
**Prompt**：
用Scikit-learn写一个电影评论情感分析脚本，用朴素贝叶斯，每行加中文注释。

**输出**：
代码有注释能看懂，但只输出了准确率，缺少精确率和召回率。

**问题**：没要求完整评估指标。

### V3 最终版
**Prompt**：
用Scikit-learn写一个电影评论情感分析脚本。用TF-IDF做特征提取，逻辑回归做分类。输出准确率、精确率、召回率、混淆矩阵。每行代码加上中文注释。训练完成后保存模型为pkl文件。

**输出**：
完整的工业级脚本，含数据加载、特征提取、模型训练、多指标评估、模型保存。

**迭代心得**：
- 明确指定模型和特征提取方式
- 列出所有需要的输出指标
- 补充代码注释和工程化要求

## 案例：数据生成

### V1
**Prompt**：
生成100条电影评论数据

**问题**：没说正负比例、没说格式、没说多样性。

### V2 最终版
**Prompt**：
请生成100条中文电影评论数据，正面和负面各50条。要求表达方式多样，避免重复。保存为CSV文件，包含review和label两列，label用1表示好评，0表示差评。

**迭代心得**：
- 必须指定正负样本比例
- 明确输出格式
- 要求表达多样性，防止模型过拟合到固定句式
